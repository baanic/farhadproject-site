# 🚀 مبانی Astro

## این بخش چیست؟

در این بخش، **Astro** را یاد می‌گیری — فریمورکی که سایت تو با آن ساخته شده.

## Astro چیست؟

**Astro** یک **Static Site Generator** است. یعنی:

- کد می‌نویسی.
- Astro کد تو را به HTML/CSS/JS تبدیل می‌کند.
- نتیجه، یک سایت فوق‌سریع است.

## چرا Astro؟

| مزیت | توضیح |
|---|---|
| **سرعت** | خروجی، HTML خالص |
| **SEO** | موتورهای جستجو دوست دارند |
| **Component-Based** | قطعه‌های قابل استفاده مجدد |
| **بدون JavaScript اضافه** | فقط جایی که لازم است |
| **آزادی در CSS** | Tailwind، CSS خالص، هر چیز |
| **Content Collections** | مدیریت محتوای Markdown |
| **Deploy ساده** | فایل‌های استاتیک |
