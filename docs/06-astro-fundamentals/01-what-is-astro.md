# Astro چیست؟

## 🎓 مفهوم

**Astro** یک **فریمورک وب مدرن** است که برای ساخت سایت‌های محتوا-محور طراحی شده.

### تعریف ساده

> Astro یک ابزار است که کد تو را می‌گیرد و در نهایت، **HTML خالص** تولید می‌کند.

## 🎓 مشکل Astro حل می‌کند

### مشکل ۱: سایت‌های React سنگین‌اند

یک سایت React/Vue معمولی:
- ۵۰۰ KB JavaScript به کاربر می‌فرستد.
- مرورگر باید اول JavaScript را دانلود کند.
- بعد اجرا کند.
- بعد صفحه را نشان دهد.

**نتیجه:** کاربر ۳–۵ ثانیه منتظر می‌ماند.

### مشکل ۲: SEO ضعیف

موتورهای جستجو (Google) JavaScript سنگین را کامل ایندکس نمی‌کنند.

**نتیجه:** سایت در نتایج جستجو پایین‌تر است.

### مشکل ۳: پیچیدگی بالا

React، Vue، Next.js — همه ابزارهای قدرتمند، اما برای یک سایت شخصی یا پرتفولیو، **بیش از حد**.

## 🎓 راه‌حل Astro

Astro سه ایده اصلی دارد:

### ۱. پیش‌فرض: صفر JavaScript

به‌جای ارسال React/Vue به مرورگر، Astro **HTML خالص** می‌فرستد.

**نتیجه:**
- صفحه در کمتر از ۱ ثانیه لود می‌شود.
- SEO عالی.
- تجربه کاربری بهتر.

### ۲. Islands Architecture

**Island Architecture** یعنی: «جزیره‌های تعاملی در دریای HTML استاتیک.»

اگر جایی نیاز به JavaScript داشته باشی (مثل فرم، منوی کشویی)، فقط **همان بخش** JavaScript می‌گیرد.

**مثال:**

```
صفحه اصلی
├── Hero (HTML خالص)
├── About (HTML خالص)
├── Portfolio (HTML خالص)
└── Contact Form (JavaScript فقط اینجا)
```

**نتیجه:** کاربر فقط JavaScript یک فرم را دانلود می‌کند، نه همه صفحه.

### ۳. Component-Based

می‌توانی از **هر فریمورکی** (React، Vue، Svelte و ...) به‌عنوان Component استفاده کنی.

**مثال:**

```astro
---
import ReactCounter from './Counter.jsx';
---

<ReactCounter client:load />
```

## 🎓 Astro در عمل

### مثال ساده

```astro
---
const title = "سلام";
---

<html>
  <head><title>{title}</title></head>
  <body>
    <h1>{title}</h1>
  </body>
</html>
```

**نتیجه در مرورگر:**

```html
<html>
  <head><title>سلام</title></head>
  <body>
    <h1>سلام</h1>
  </body>
</html>
```

**بدون هیچ JavaScript اضافه.**

## 🎓 Astro چگونه کار می‌کند؟

### مرحله ۱: نوشتن

تو فایل‌های `.astro` می‌نویسی.

### مرحله ۲: Build

با دستور `npm run build`:
- Astro همه فایل‌ها را می‌خواند.
- Componentها را ترکیب می‌کند.
- داده‌ها را در HTML می‌ریزد.
- خروجی در پوشه `dist/`.

### مرحله ۳: Deploy

پوشه `dist` را روی سرور می‌گذاری.
- کاربر وارد سایت می‌شود.
- HTML دریافت می‌کند.
- تمام. سریع.

## 🎓 Astro vs فریمورک‌های دیگر

| فریمورک | مناسب برای | حجم خروجی |
|---|---|---|
| **React SPA** | اپلیکیشن تعاملی | سنگین |
| **Next.js** | اپلیکیشن پیچیده | متوسط |
| **Vue/Nuxt** | مشابه بالا | متوسط |
| **Gatsby** | سایت محتوا-محور | متوسط |
| **Astro** ✅ | سایت محتوا-محور | خیلی سبک |

## 🎓 Astro چه سایت‌هایی می‌سازد؟

- سایت‌های شخصی
- پرتفولیو
- بلاگ
- مستندات فنی
- فروشگاه‌های کوچک
- سایت‌های شرکت

**و چه سایت‌هایی نمی‌سازد؟**
- اپلیکیشن‌های پیچیده SPA
- داشبوردهای تعاملی با داده‌های زنده
- شبکه‌های اجتماعی

## 🎓 نمونه‌های واقعی

Astro توسط شرکت‌ها و پروژه‌های زیر استفاده می‌شود:

- **astrosites.io** — گالری سایت‌های Astro
- **Firebase blog** (قبلاً)
- **Webflow blog** (قبلاً)
- **Google Chrome DevTools**
- **Unilever** (بخشی)
