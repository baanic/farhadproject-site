# 🚀 Deploy روی Liara

## این بخش چیست؟

در این بخش، سایت را از **کامپیوتر خودت** به **اینترنت** منتقل می‌کنی.

## Deploy چیست؟

**تا این لحظه:** سایت روی `localhost:4321` است. فقط تو می‌بینی.

**بعد از Deploy:** سایت روی `farhadproject.ir` است. همه می‌بینند.

## چرا Liara؟

| مزیت | توضیح |
|---|---|
| **Deploy آسان** | با یک دستور |
| **پشتیبانی Astro** | کاملاً سازگار |
| **SSL رایگان** | خودکار |
| **CDN ایرانی** | سریع برای کاربران ایرانی |
| **پنل فارسی** | مدیریت ساده |
| **پلن رایگان** | برای شروع کافی |
