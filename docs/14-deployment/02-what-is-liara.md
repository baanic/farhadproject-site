# Liara چیست؟

## 🎓 مفهوم

**Liara** یک **PaaS** ایرانی است. یعنی: «Platform as a Service».

### قیاس

تصور کن می‌خواهی ماشین بسازی:
- **بدون PaaS:** خودت موتور، شاسی، صندلی می‌سازی.
- **با PaaS:** بدنه را می‌سازی، بقیه آماده.

**PaaS یعنی:** فقط کدت را بده، بقیه (سرور، SSL، CDN) با ما.

## 🎓 Liara چه می‌دهد؟

| سرویس | کاربرد |
|---|---|
| **Static Hosting** | سایت‌های استاتیک |
| **Node.js** | اپ‌های Backend |
| **Python** | Django، Flask |
| **Docker** | Container |
| **Database** | MySQL، PostgreSQL، MongoDB |
| **Object Storage** | فایل‌ها |
| **CDN** | توزیع محتوا |
| **DNS** | مدیریت دامنه |

## 🎓 چرا Liara؟

### ۱. ایرانی

- سرور داخل ایران
- **سرعت بالا** برای کاربران ایرانی
- **پشتیبانی فارسی**
- **پرداخت ریالی**

### ۲. سازگار با Astro

Liara در مستندات رسمی از Astro پشتیبانی می‌کند.

### ۳. Deploy ساده

با یک دستور:

```bash
liara deploy
```

### ۴. SSL رایگان

گواهی Let's Encrypt خودکار.

### ۵. CDN

شبکه توزیع محتوا برای سرعت.

### ۶. پلن رایگان

برای شروع کافی.

## 🎓 پلن‌های Liara

| پلن | قیمت | منابع |
|---|---|---|
| **رایگان** | ۰ | ۱ اپ، منابع محدود |
| **حرفه‌ای** | ماهانه | اپ بیشتر، منابع بیشتر |
| **سازمانی** | بیشتر | برای سازمان‌ها |

**ما از پلن رایگان استفاده می‌کنیم.**

**محدودیت‌های پلن رایگان:**
- ۱ اپ
- ۱۰۰MB RAM
- ۵۰۰MB دیسک
- بدون دامنه اختصاصی (اما اتصال CNAME امکان دارد)
- بدون SLA

**نکته:** برای سایت استاتیک کوچک، کافی است.

## 🎓 چرا این ترکیب؟

**Astro Static + Liara = سایت سریع و حرفه‌ای.**

- Astro: خروجی HTML خالص
- Liara: سرور سریع در ایران
- نتیجه: بارگذاری زیر ۱ ثانیه
