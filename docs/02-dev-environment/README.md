# 🛠 محیط توسعه

## این بخش چیست؟

در این بخش، **محیط توسعه** را راه‌اندازی می‌کنیم. یعنی ابزارهایی که برای ساخت سایت لازم داری.

## چرا این بخش مهم است؟

بدون محیط توسعه، نمی‌توانی حتی یک خط کد بنویسی. مثل نجاری است که بدون کارگاه، چکش و اره، نمی‌تواند کار کند.

## چه چیزی نصب می‌کنیم؟

| ابزار | کاربرد | فایل |
|---|---|---|
| **Node.js** | اجرای JavaScript خارج از مرورگر | [01](./01-what-is-nodejs.md) |
| **npm** | مدیریت پکیج‌ها | [02](./02-what-is-npm.md) |
| **nvm** | مدیریت نسخه‌های Node | [03](./03-install-nvm.md) |
| **Node (نصب)** | نصب عملی | [04](./04-install-node.md) |
| **VS Code** | ویرایشگر کد | [05](./05-install-vscode.md) |

## ترتیب نصب

نصب باید **به این ترتیب** انجام شود:

```
nvm → Node → npm → VS Code
```

**چرا؟**
- `nvm` ابزاری برای مدیریت نسخه‌های Node است.
- بدون `nvm`، اگر بخواهی نسخه Node را عوض کنی، باید دستی حذف و نصب کنی.
- `npm` همراه `Node` نصب می‌شود.
- `VS Code` آخر نصب می‌شود چون به Node نیازی ندارد.

## چرا Homebrew را نصب نکردیم؟

اگر یادت باشد، در روز اول تلاش کردیم Homebrew نصب کنیم، اما با خطای «Only supported on Apple Silicon» مواجه شدیم.

**علت:** تیم توسعه Homebrew از سپتامبر ۲۰۲۴، پشتیبانی از مک‌های Intel را به سطح «Tier 3» (پشتیبانی پایین) منتقل کرده و نصب‌کننده گرافیکی جدید، فقط روی Apple Silicon کار می‌کند.

**راه‌حل:** به‌جای Homebrew، مستقیم `nvm` را با اسکریپت رسمی نصب کردیم. این روش هم ساده‌تر است و هم روی همه مک‌ها کار می‌کند.

## پیش‌نیاز: Xcode Command Line Tools

اگر روی مک هستی، احتمالاً این ابزارها از قبل نصب هستند. برای بررسی:

```bash
xcode-select -p
```

اگر مسیری مثل `/Library/Developer/CommandLineTools` دیدی، نصب است.

اگر نبود:

```bash
xcode-select --install
```
