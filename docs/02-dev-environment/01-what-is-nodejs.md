# Node.js چیست؟

## 🎓 مفهوم

**Node.js** یک **محیط اجرای JavaScript** در خارج از مرورگر است.

### قبل از Node.js

در دهه ۹۰ و ۲۰۰۰:
- JavaScript فقط در مرورگر اجرا می‌شد (Chrome, Firefox, Safari).
- اگر می‌خواستی سرور بسازی، باید PHP، Python، Ruby یا Java می‌نوشتی.

### سال ۲۰۰۹

**Ryan Dahl** آمد و Node.js را ساخت. ایده‌اش ساده بود:

> «JavaScript موتور فوق‌العاده‌ای دارد (V8 از Chrome). چرا از آن برای سرور استفاده نکنیم؟»

نتیجه: **Node.js**.

## 🎓 Node.js چطور کار می‌کند؟

Node.js از **موتور V8** (موتور JavaScript در Chrome) استفاده می‌کند. یعنی:

- همان زبانی که در مرورگر می‌نویسی، در Node.js هم می‌نویسی.
- اما Node.js می‌تواند به فایل‌سیستم، شبکه و منابع سیستم دسترسی داشته باشد.

### مقایسه

| JavaScript در مرورگر | JavaScript در Node.js |
|---|---|
| فقط با DOM کار می‌کند | با فایل، سرور، شبکه |
| محدود به امنیت مرورگر | دسترسی کامل |
| فقط در صفحه وب | در ترمینال، سرور، ابزار CLI |

## 🎓 چرا Node.js برای ما مهم است؟

پروژه ما با **Astro** ساخته شده. Astro:

1. یک ابزار **JavaScript** است.
2. با **Node.js** اجرا می‌شود.
3. `npm` (ابزار مدیریت پکیج) بخشی از Node است.

**پس Node.js، پیش‌نیاز اصلی کار ماست.**

## 🎓 Node.js فقط برای وب نیست

Node.js کاربردهای زیادی دارد:

| کاربرد | مثال |
|---|---|
| وب‌سرور | Express, Fastify, NestJS |
| ابزار CLI | npm, yarn, vite |
| Build Tools | Webpack, Vite, Astro |
| Desktop App | Electron (VS Code با آن ساخته شده) |
| IoT | Johnny-Five, Node-RED |

**VS Code** که داری ازش استفاده می‌کنی، خودش با **Electron** ساخته شده که روی Node.js اجرا می‌شود.

## 🎓 نسخه‌های Node.js

Node.js نسخه‌های مختلفی دارد:

| نوع نسخه | توضیح | مناسب برای |
|---|---|---|
| **Current** | جدیدترین، اما ممکن است ناپایدار | تست ویژگی‌های جدید |
| **LTS** | Long Term Support — پایدار، پشتیبانی بلندمدت | پروژه‌های تولیدی |
| **Maintenance LTS** | پشتیبانی طولانی‌تر | پروژه‌های قدیمی |
| **Odd/Even** | شماره فرد = ناپایدار، زوج = پایدار | — |

**ما از LTS استفاده می‌کنیم.** چرا؟ چون پایدار است و برای پروژه‌های جدی توصیه می‌شود.

## 🎓 نسخه‌های فعلی

در لحظه نوشتن این سند (آذر ۱۴۰۴):
- **آخرین LTS:** Node 20.x یا 22.x
- **آخرین Current:** Node 23.x

**ما نسخه LTS نصب کردیم** که در سیستم تو `v24.x.x` شد (آخرین LTS در زمان نصب).

## 🛠 چگونه Node.js را نصب کنیم؟

از طریق **nvm** (Node Version Manager). چرا nvm و نه نصب مستقیم؟

| نصب مستقیم | نصب با nvm |
|---|---|
| یک نسخه Node | چند نسخه، سوئیچ سریع |
| تغییر نسخه سخت | `nvm use 18` و تمام |
| مدیریت پکیج‌های global سخت | راحت |

**در گام بعدی، nvm را نصب می‌کنیم.**

## 💡 چرا Node.js؟

اگر Node.js را نمی‌داشتی:

- نمی‌توانستی Astro را نصب کنی.
- نمی‌توانستی `npm run dev` بزنی.
- نمی‌توانستی پروژه را Build کنی.
- **هیچ چیزی از این پروژه کار نمی‌کرد.**

پس این نصب، **اولین قدم اساسی** است.

## 🎁 خلاصه

| مفهوم | توضیح |
|---|---|
| Node.js | محیط اجرای JavaScript خارج از مرورگر |
| موتور | V8 (از Chrome) |
| پیش‌نیاز | Astro، npm و ... |
| نسخه پیشنهادی | LTS |
