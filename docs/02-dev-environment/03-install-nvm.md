# نصب nvm

## 🎓 nvm چیست؟

**nvm** مخفف **Node Version Manager**.

### چرا به آن نیاز داریم؟

تصور کن:
- پروژه A با Node 18 کار می‌کند.
- پروژه B با Node 20 کار می‌کند.
- پروژه C با Node 22 کار می‌کند.

بدون nvm، باید برای هر پروژه Node را حذف و نصب کنی. **غیرقابل تحمل.**

با nvm:
```bash
nvm use 18    # سوئیچ به 18
nvm use 20    # سوئیچ به 20
nvm use 22    # سوئیچ به 22
```

**یک دستور، تغییر کامل.**

## 🎓 چرا nvm و نه Homebrew؟

در روز اول، تلاش کردیم Homebrew نصب کنیم. اما با خطا مواجه شدیم:

```
Homebrew on macOS is only supported on Apple Silicon processors!
```

**علت:** Homebrew از سپتامبر ۲۰۲۴، پشتیبانی از Intel Mac را کاهش داده و نصب‌کننده گرافیکی جدید فقط روی Apple Silicon کار می‌کند.

**راه‌حل:** نصب مستقیم nvm با اسکریپت رسمی. این روش:
- روی همه مک‌ها کار می‌کند.
- سبک‌تر است.
- پیشنهاد خود تیم nvm است.

## 🛠 نصب nvm

### گام ۱: اجرای اسکریپت نصب

در ترمینال این دستور را بزن:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
```

**این دستور چه می‌کند؟**

| بخش | کار |
|---|---|
| `curl` | دانلود از اینترنت |
| `-o-` | خروجی به stdout |
| `https://...` | آدرس اسکریپت نصب |
| `\| bash` | اجرای اسکریپت با bash |

**چه اتفاقی می‌افتد؟**
1. اسکریپت دانلود می‌شود.
2. اسکریپت اجرا می‌شود.
3. nvm در `~/.nvm` نصب می‌شود.
4. چند خط به فایل `~/.zshrc` اضافه می‌شود.

**زمان:** حدود ۱۰–۳۰ ثانیه.

## 🎓 مفهوم: `~/.zshrc`

فایل `~/.zshrc` یک فایل متنی است که **هر بار ترمینال جدید باز می‌کنی، اجرا می‌شود.**

**مثال محتوای این فایل:**

```bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
[ -s "$NVM_DIR/bash_completion" ] && \. "$NVM_DIR/bash_completion"
```

این خطوط به Shell می‌گویند: «nvm را در این مسیر پیدا کن و فعال کن.»

**چرا لازم است؟**
بدون این خطوط، هر بار ترمینال جدید باز کنی، nvm ناپدید می‌شود.

## 🛠 گام ۲: فعال‌سازی nvm در ترمینال فعلی

پس از نصب، nvm فقط در ترمینال‌های **جدید** فعال است. برای فعال‌سازی در ترمینال فعلی:

```bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
```

**یا ساده‌تر:**

```bash
source ~/.zshrc
```

## 🛠 گام ۳: بررسی نصب

```bash
nvm --version
```

باید نسخه‌ای مثل `0.40.4` نشان دهد.

**اگر خطا داد:**

```
zsh: command not found: nvm
```

یعنی فایل `~/.zshrc` درست تنظیم نشده. این دستور را بزن تا محتوایش را ببینی:

```bash
cat ~/.zshrc
```

باید خطوط مربوط به nvm را ببینی.

## 🎓 دستورات مهم nvm

| دستور | کار |
|---|---|
| `nvm --version` | نمایش نسخه nvm |
| `nvm install --lts` | نصب آخرین LTS |
| `nvm install 20` | نصب نسخه 20 |
| `nvm use 20` | سوئیچ به 20 |
| `nvm use --lts` | سوئیچ به آخرین LTS |
| `nvm current` | نسخه فعلی |
| `nvm ls` | لیست نسخه‌های نصب‌شده |
| `nvm ls-remote` | لیست نسخه‌های موجود در سرور |
| `nvm alias default 20` | تنظیم 20 به‌عنوان پیش‌فرض |
| `nvm uninstall 18` | حذف نسخه 18 |

## 🎓 ترفند: Default Alias

برای اینکه هر بار ترمینال جدید باز می‌کنی، یک نسخه خاص فعال شود:

```bash
nvm alias default node
```

یا:

```bash
nvm alias default 20
```

`node` یعنی «آخرین نصب‌شده». `20` یعنی «دقیقاً نسخه 20».

## 🛑 عیب‌یابی

### مشکل ۱: `command not found: nvm` بعد از نصب

**راه‌حل:**

1. بررسی کن فایل `.zshrc` وجود دارد:
   ```bash
   ls -la ~/.zshrc
   ```

2. اگر وجود ندارد، بساز:
   ```bash
   touch ~/.zshrc
   ```

3. اسکریپت نصب را دوباره اجرا کن:
   ```bash
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
   ```

4. ترمینال را ببند و باز کن.

### مشکل ۲: نصب اسکریپت خطا می‌دهد

**خطای احتمالی:** `HTTP request failed`

**راه‌حل:**
- اتصال اینترنت را بررسی کن.
- از VPN استفاده کن (اگر سرور GitHub در ایران کند است).
- چند دقیقه بعد دوباره تلاش کن.

### مشکل ۳: بعد از نصب، نسخه تغییر نمی‌کند

**راه‌حل:**
- مطمئن شو از `nvm use` استفاده می‌کنی.
- اگر `nvm use 20` خطا داد، اول `nvm install 20` بزن.

## 🎁 خلاصه

| مفهوم | توضیح |
|---|---|
| nvm | مدیریت نسخه‌های Node |
| محل نصب | `~/.nvm` |
| تنظیم | `~/.zshrc` |
| دستور اصلی | `nvm install` و `nvm use` |
