# 🔗 اتصال داده

## این بخش چیست؟

در این بخش، یاد می‌گیری چطور **Master Data** را به سایت Astro وصل کنی.

## چرا اتصال داده مهم است؟

بدون اتصال داده:
- هر مقدار را دستی در HTML می‌نویسی.
- تغییر داده، نیاز به ویرایش کد دارد.
- تکرار و خطا.

با اتصال داده:
- داده در `master_data.json`.
- کد از داده می‌خواند.
- تغییر داده، خودکار در سایت.
