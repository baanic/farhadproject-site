# سیستم رنگی پروژه

## 🎓 مفهوم

**سیستم رنگی** مجموعه‌ای از رنگ‌های هماهنگ است که در کل پروژه استفاده می‌شود.

## 🎓 چرا سیستم رنگی؟

### بدون سیستم

- هر جا رنگ دلخواه.
- ناهماهنگی.
- تغییر رنگ سخت.

### با سیستم

- هماهنگی.
- تغییر یک خط، همه‌جا اعمال.
- حرفه‌ای.

## 🎓 چرا این رنگ‌ها؟

### سرمه‌ای (`#1B2A4A`)

- **رسمی و مهندسی.**
- اعتماد و اقتدار.
- خوانایی بالا با متن سفید.
- مناسب مخاطب دولتی و پیمانکار.

### مسی (`#B8763E`)

- **گرم و انسانی.**
- جلب توجه ملایم.
- تضاد خوب با سرمه‌ای.
- حس کلاسیک.

### کرم (`#F5F0E6`)

- **خوانایی بالا.**
- گرم‌تر از سفید خالص.
- چشم را اذیت نمی‌کند.

## 🛠 استفاده در کد

### در Inline Style

```astro
<div style="background: #1B2A4A; color: #F5F0E6;">
  محتوا
</div>
```

### در `<style>`

```css
.card {
  background: #FFFFFF;
  color: #1C1C1C;
  border: 1px solid #D9D4C8;
}

.card:hover {
  border-color: #B8763E;
}
```

### متغیرهای CSS

```astro
<div class="card">
  محتوا
</div>

<style>
  .card {
    --primary: #1B2A4A;
    --accent: #B8763E;
    --bg-light: #F5F0E6;

    background: var(--primary);
    border-color: var(--accent);
  }
</style>
```

## 🎓 قواعد استفاده

### قاعده ۱: پس‌زمینه صفحات

**کرم روشن** `#F5F0E6` یا **سفید** `#FFFFFF`.

**توصیه:** صفحات اصلی سفید، بخش‌های تأکیدی کرم.

### قاعده ۲: عناوین

| نوع | رنگ |
|---|---|
| H1 | سرمه‌ای `#1B2A4A` |
| H2 | سرمه‌ای |
| H3 | سرمه‌ای |
| زیرعنوان | مسی `#B8763E` |

### قاعده ۳: متن بدنه

ذغالی `#1C1C1C` برای خوانایی.

### قاعده ۴: کپشن و متن ثانویه

خاکستری سرد `#4A5568`.

### قاعده ۵: دکمه‌ها

```astro
<button style="
  background: #1B2A4A;
  color: #F5F0E6;
  padding: 14px 32px;
  border-radius: 8px;
">
  ارسال
</button>
```

**Hover:** کمی تیره‌تر.

### قاعده ۶: کارت‌ها

**سفید** روی پس‌زمینه کرم. مرز نازک خاکستری روشن.

## 🎓 استفاده در پروژه ما

### `Navbar.astro`

  background: #1B2A4A;

```astro

  <div style="color: #4A5568;">{label}</div>
  <div style="color: #1B2A4A;">{value}</div>
</div>
```

### `ProjectHero.astro`

```astro

  <div style={`background: ${stat.color}; color: #F5F0E6;`}>
    <div>{stat.value}</div>
    <div>{stat.label}</div>
  </div>
))}
```

**رنگ هر کارت، از داده می‌آید.**

```astro

  background: linear-gradient(135deg, #1B2A4A 0%, #2D5C8A 100%);

">
```

**گرادیانت سرمه‌ای به آبی.**

## 🎓 Contrast Ratio (نسبت تضاد)

برای خوانایی، **WCAG** استانداردی دارد:

| نسبت | سطح |
|---|---|
| 4.5:1 | AA (حداقل) |
| 7:1 | AAA (عالی) |

**بررسی:** [contrast-ratio.com](https://contrast-ratio.com).

**مثال ما:**

- سرمه‌ای روی کرم: **12.3:1** ✅
- مسی روی سرمه‌ای: **4.8:1** ✅

## 🎓 رنگ در Media Query

```css
.card {
  background: #FFFFFF;
}

@media (prefers-color-scheme: dark) {
  .card {
    background: #1B2A4A;
    color: #F5F0E6;
  }
}
```
