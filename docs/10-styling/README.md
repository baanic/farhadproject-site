# 🎨 استایل و طراحی

## این بخش چیست؟

در این بخش، **تصمیمات طراحی** سایت تو را مرور می‌کنیم:
- CSS چیست و چطور در Astro کار می‌کند.
- پالت رنگی.
- فونت Shabnam.
- Responsive Design.

## چرا استایل مهم است؟

یک سایت خوب، فقط کد نیست. **چطور دیده می‌شود** هم مهم است:
- **اولین برداشت:** کاربر در ۳ ثانیه قضاوت می‌کند.
- **خوانایی:** متن راحت خوانده شود.
- **اعتماد:** طراحی حرفه‌ای، اعتماد می‌سازد.
- **تجربه موبایل:** بیش از ۶۰٪ کاربران با موبایل می‌آیند.

## اصول طراحی ما

1. **مینیمال:** هیچ چیز اضافه.
2. **خوانا:** فضای سفید کافی.
3. **رسمی:** مخاطب کارفرما.
4. **فارسی-محور:** RTL، فونت فارسی.
5. **Responsive:** موبایل اول.
