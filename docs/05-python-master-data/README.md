# 🐍 Master Data با Python

## این بخش چیست؟

در این بخش، یاد می‌گیری چطور **Master Data** پروژه را با **Python** ساختی.

## Master Data چیست؟

یک **پایگاه داده مرکزی** از تمام اطلاعات پروژه:
- مشخصات پروژه
- فضاها و ابعاد
- لایه‌بندی آکوستیک
- تأسیسات
- متره و برآورد
- زمان‌بندی
- پست‌های شبکه‌های اجتماعی

## چرا Python؟

| گزینه | مزیت | عیب |
|---|---|---|
| Excel دستی | آسان | تغییرات دستی سخت |
| Python + pandas | خودکار، دقیق، قابل توسعه | نیاز به یادگیری |
| JavaScript | همه‌کاره | برای داده خوب نیست |
| SQL | قدرتمند | نیاز به دیتابیس |
