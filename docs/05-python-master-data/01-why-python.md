# چرا Python؟

## 🎓 مفهوم

**Python** یک زبان برنامه‌نویسی سطح بالا، همه‌کاره و ساده است.

## 🎓 چرا Python برای Master Data؟

### ۱. سادگی

Python کد **خوانا و شبیه انگلیسی** دارد:

```python
# Python
name = "فرهاد"
age = 30
print(f"سلام {name}، سن: {age}")
```

در مقایسه با Java:

```java
// Java
String name = "فرهاد";
int age = 30;
System.out.println("سلام " + name + "، سن: " + age);
```

### ۲. کتابخانه‌های قدرتمند

| کتابخانه | کاربرد |
|---|---|
| **pandas** | پردازش داده (Excel، CSV، JSON) |
| **openpyxl** | ساخت و ویرایش Excel |
| **json** | کار با JSON |
| **numpy** | محاسبات عددی |
| **matplotlib** | نمودار |

### ۳. تبدیل داده به فرمت‌های مختلف

با Python می‌توانی داده را:
- از Excel بخوانی.
- به JSON تبدیل کنی.
- در وب‌سایت استفاده کنی.
- در Excel ذخیره کنی.

**همه با یک اسکریپت.**

### ۴. خودکارسازی

هر بار پروژه جدیدی اضافه می‌کنی، فقط داده را در اسکریپت به‌روز می‌کنی. Excel و JSON خودکار ساخته می‌شوند.

## 🎓 Master Data در پروژه ما

چرا Master Data لازم داشتیم؟

**مشکل:**

- داده‌های پروژه در **۱۵ فایل Excel مختلف** پراکنده بود.
- هر فایل ساختار متفاوتی داشت.
- برای وب‌سایت، به داده **متمرکز** نیاز داشتیم.
- به‌روزرسانی دستی، زمان‌بر و خطاپذیر بود.

**راه‌حل:**

یک اسکریپت Python نوشتیم که:
1. تمام داده را در **یک ساختار** جمع می‌کند.
2. Excel حرفه‌ای تولید می‌کند.
3. JSON آماده برای وب تولید می‌کند.

**نتیجه:**

- یک منبع واحد حقیقت (SSOT).
- به‌روزرسانی سریع.
- داده قابل اتکا.

## 🎓 چرا Python و نه JavaScript؟

JavaScript هم می‌تواند این کار را بکند. اما:

| معیار | Python | JavaScript |
|---|---|---|
| پردازش داده | ✅ عالی | ⚠️ خوب |
| Excel | ✅ openpyxl | ⚠️ کتابخانه‌های کمتر |
| سرعت توسعه | ✅ سریع | ⚠️ کندتر |
| جامعه داده | ✅ بزرگ | ⚠️ کوچک‌تر |

**Python استاندارد صنعت برای پردازش داده است.**
