# معرفی Web3Forms

## 🎓 مفهوم

**Web3Forms** یک سرویس **Backend-as-a-Service** است که فرم‌های HTML را به ایمیل شما وصل می‌کند.

## 🎓 چطور کار می‌کند؟

### مرحله ۱: ثبت‌نام

با ایمیل خودت ثبت‌نام می‌کنی.

### مرحله ۲: گرفتن Access Key

یک کلید طولانی که به تو می‌دهد.

### مرحله ۳: استفاده در فرم

کلید را در فرم قرار می‌دهی.

### مرحله ۴: تمام

هر ارسال، به ایمیل تو می‌رسد.

## 🎓 مزایا

| مزیت | توضیح |
|---|---|
| **رایگان** | ۲۵۰ پیام در ماه |
| **بدون ثبت‌نام پیچیده** | فقط ایمیل |
| **ساده** | یک Access Key |
| **سازگار** | با هر فریمورک |
| **ضد اسپم** | Botcheck |
| **HTTPS** | امن |

## 🎓 معایب

| عیب | توضیح |
|---|---|
| **محدودیت پیام** | ۲۵۰ در ماه |
| **وابستگی به سرویس** | اگر Web3Forms قطع شود |
| **بدون فایل پیوست** | در پلن رایگان |
| **لاگ محدود** | تاریخچه کم |

## 🎓 مقایسه با گزینه‌های دیگر

| سرویس | مزیت | عیب |

- ساده‌ترین.
- رایگان کافی.
- بدون محدودیت پلتفرم.

## 🎓 ساختار Web3Forms

### URL API

```
https://api.web3forms.com/submit
```

### Body درخواست

```json
{
  "access_key": "YOUR-KEY",
  "name": "فرهاد",
  "email": "user@example.com",
  "subject": "موضوع",
  "message": "پیام"
}
```

### پاسخ

```json
{
  "success": true,
  "message": "Email sent successfully"
}
```

## 🎓 ویژگی‌های اضافی

### ۱. Auto-Response

اگر بخواهی به کاربر ایمیل خودکار بفرستی:

```
From: your@email.com
To: user@example.com
Subject: پیام شما دریافت شد
```

**در پنل Web3Forms فعال می‌کنی.**

### ۲. Custom Redirect

پس از ارسال موفق، کاربر را به صفحه تشکر ببری.

### ۳. Domain Restriction

فقط از دامنه‌های مجاز کار کند.

### ۴. reCAPTCHA

ضد اسپم قوی‌تر (پلن حرفه‌ای).

### ۵. File Upload

پیوست فایل (پلن حرفه‌ای).

## 🎓 امنیت

### Access Key

- **محرمانه نیست.**
- در HTML قابل مشاهده.
- **اما** فقط برای ایمیل تو کار می‌کند.
- کسی نمی‌تواند به ایمیل تو دسترسی پیدا کند.

### HTTPS

تمام ارتباط **رمزنگاری‌شده** است.

### Rate Limiting

Web3Forms جلوی ارسال زیاد از یک IP را می‌گیرد.
