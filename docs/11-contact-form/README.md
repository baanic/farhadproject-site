# 📬 فرم تماس

## این بخش چیست؟

در این بخش، یاد می‌گیری چطور **فرم تماس** را در یک سایت **Static** پیاده‌سازی کنی.

## چالش: سایت Static، فرم Dynamic

**سایت ما Static است.** یعنی:
- بدون سرور.
- بدون دیتابیس.
- بدون Backend.

**اما فرم تماس نیاز دارد به:**
- دریافت داده از کاربر.
- فرستادن ایمیل.
- پاسخ.

**راه‌حل:** استفاده از سرویس خارجی (Web3Forms).

## چرا Web3Forms؟

| مزیت | توضیح |
|---|---|
| **رایگان** | تا ۲۵۰ پیام در ماه |
| **بدون ثبت‌نام پیچیده** | فقط ایمیل |
| **بدون Backend** | از سمت مرورگر |
| **ساده** | یک Access Key |
| **ضد اسپم** | Botcheck داخلی |

        ↓
