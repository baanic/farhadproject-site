# 🔧 نگهداری و توسعه

## این بخش چیست؟

در این بخش، یاد می‌گیری چطور سایت را **در آینده** توسعه و نگهداری کنی.

## چرا این بخش مهم است؟

سایت یک بار ساخته نمی‌شود. **هر ماه، هر سال، تغییر می‌کند.**

- پروژه جدید اضافه می‌شود.
- متن عوض می‌شود.
- بخش جدید اضافه می‌شود.
- باگ پیدا می‌شود.

## سطوح نگهداری

### سطح ۱: تغییر محتوا

فقط متن یا داده را عوض می‌کنی.

**ابزار:** `master_data_builder.py`.

### سطح ۲: افزودن پروژه

پروژه جدیدی به پرتفولیو اضافه می‌کنی.

**ابزار:** `master_data_builder.py`.

### سطح ۳: افزودن بخش

بخش جدیدی به سایت اضافه می‌کنی.

**ابزار:** VS Code + Astro.

### سطح ۴: تغییر طراحی

پالت، فونت، یا چیدمان را عوض می‌کنی.

**ابزار:** VS Code + CSS.
