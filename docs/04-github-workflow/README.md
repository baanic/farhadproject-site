# 🐙 کار با GitHub

## این بخش چیست؟

در این بخش، یاد می‌گیری چطور با **GitHub** به‌عنوان سرویس آنلاین کار کنی:
- مخزن بسازی.
- کد محلی را به GitHub وصل کنی.
- Push و Pull کنی.
- README و Markdown بنویسی.
- `.gitignore` مدیریت کنی.

## چرا این بخش مهم است؟

Git بدون GitHub، یک ابزار محلی است. **GitHub آن را به یک ابزار حرفه‌ای تبدیل می‌کند:**

- بکاپ آنلاین
- همکاری تیمی
- Deploy خودکار
- پروفایل عمومی برای کارفرما

## پیش‌نیاز

- Git نصب و تنظیم شده.
- حساب GitHub داری.
- Personal Access Token ساخته‌ای.

## فلو کلی

```
[ساخت Repo در GitHub]
        ↓
[git init محلی]
        ↓
[git remote add origin URL]
        ↓
[git add + git commit]
        ↓
[git push -u origin main]
        ↓
[کد روی GitHub است!]
```
