# 🔍 SEO

## این بخش چیست؟

در این بخش، **SEO** (Search Engine Optimization) را یاد می‌گیری.

## SEO چیست؟

**SEO** = بهینه‌سازی سایت برای موتورهای جستجو (Google، Bing و ...).

**هدف:** سایت در نتایج جستجو **بالاتر** بیاید.

## چرا SEO مهم است؟

### آمار

- **بیش از ۹۰٪** ترافیک وب از موتورهای جستجو می‌آید.
- **۷۵٪** کاربران از صفحه اول نتایج فراتر نمی‌روند.
- **بیش از ۵۰٪** کلیک‌ها روی ۳ نتیجه اول است.

## چرا برای ما مهم است؟

- **کارفرمای آینده** ممکن است تو را در Google جستجو کند.
- **پروژه‌های بیشتر** از ترافیک ارگانیک.
- **اعتبار حرفه‌ای.**

## انواع SEO

| نوع | توضیح |
|---|---|
| **On-Page** | داخل سایت (محتوا، تگ‌ها) |
| **Off-Page** | خارج سایت (بک‌لینک) |
| **Technical** | فنی (سرعت، موبایل) |

**ما روی On-Page و Technical تمرکز می‌کنیم.**

## اصول SEO ما

1. **محتوا:** مفید و اصیل.
2. **ساختار:** عنوان‌ها، پاراگراف‌ها.
3. **Meta Tags:** عنوان و توضیح.
4. **سرعت:** سایت استاتیک، سریع.
5. **موبایل:** Responsive.
