# 💻 مبانی ترمینال

## این بخش برای چه کسی است؟

اگر تا حالا با ترمینال کار نکرده‌ای یا فقط چند دستور ساده بلدی، این بخش برای توست.

## چرا ترمینال یاد بگیریم؟

### دلیل ۱: ترمینال، زبان مادری کامپیوتر است
رابط گرافیکی (GUI) یک لایه ترجمه است. ترمینال، مستقیم‌ترین راه صحبت با سیستم‌عامل است.

### دلیل ۲: سرعت
یک دستور `mkdir -p a/b/c` در ۲ ثانیه پوشه‌های تو در تو می‌سازد. در GUI، باید ۳ بار راست‌کلیک و New Folder بزنی.

### دلیل ۳: خودکارسازی
در ترمینال می‌توانی اسکریپت بنویسی که کارهای تکراری را خودکار کند.

### دلیل ۴: ابزارهای توسعه
همه ابزارهای برنامه‌نویسی (Git، npm، Python، Astro CLI) از ترمینال اجرا می‌شوند. بدون ترمینال، نمی‌توانی برنامه‌نویسی کنی.

## یک توصیه مهم

**خواندن کافی نیست.** هر دستور را در ترمینال خودت اجرا کن. حتی اگر فقط یک تمرین است.

بهترین یادگیری از ترمینال، **تجربه عملی** است. حتی اگر اشتباه کنی. اگر خرابکاری کردی، مشکلی نیست — ما همه چیز را در Git داریم.

## پیش‌نیاز

ترمینال مک را باز کن:
- **Command + Space** بزن
- تایپ کن **Terminal**
- Enter بزن

یا در VS Code:
- **View → Terminal**
- یا **Ctrl + `**
