# مسیریابی در ترمینال

## 🎓 مفهوم

در ترمینال، همیشه در **یک پوشه** هستی. این پوشه را **پوشه کاری** (Working Directory) می‌گویند.

برای اینکه کار کنی، باید:
1. بدانی **کجا هستی** (`pwd`).
2. بدانی **چه چیزی اینجاست** (`ls`).
3. بتوانی **جابه‌جا شوی** (`cd`).

## 🎓 مفهوم: مسیر (Path)

هر فایل و پوشه در کامپیوتر، یک **آدرس یکتا** دارد به نام **مسیر**.

### دو نوع مسیر

| نوع | توضیح | مثال |
|---|---|---|
| **مسیر مطلق** (Absolute) | از ریشه `/` شروع می‌شود | `/Users/macuser/Documents` |
| **مسیر نسبی** (Relative) | از پوشه فعلی شروع می‌شود | `Documents/Projects` |

### علائم خاص

| علامت | معنی |
|---|---|
| `/` | ریشه فایل‌سیستم |
| `~` | پوشه Home کاربر |
| `.` | پوشه فعلی |
| `..` | پوشه والد (یک مرحله بالا) |
| `-` | پوشه قبلی (برای `cd`) |

## 🛠 دستور ۱: `pwd` — من کجا هستم؟

**P**rint **W**orking **D**irectory

```bash
pwd
```
خروجی نمونه:
```
/Users/macuser
```

## 🛠 دستور ۲: `ls` — چه چیزی اینجاست؟

**L**i**s**t — لیست کردن محتوای پوشه

### حالت پایه

```bash
ls
```

خروجی: فقط نام فایل‌ها و پوشه‌ها.

### حالت کامل `-l`

```bash
ls -l
```

خروجی: با جزئیات (مجوزها، مالک، حجم، تاریخ).

### حالت کامل با فایل‌های مخفی `-la`

```bash
ls -la
```

خروجی: شامل فایل‌های مخفی (مثل `.git`، `.env`).

### ترکیب فلگ‌ها

می‌توانی فلگ‌ها را با هم بنویسی:
```bash
ls -lah
```
- `l` = Long format
- `a` = All files (شامل مخفی)
- `h` = Human readable (حجم به KB/MB/GB)

### لیست یک پوشه خاص

```bash
ls Documents
ls /Users/macuser/Documents
ls ~/Documents/Projects
```

## 🛠 دستور ۳: `cd` — جابه‌جا شدن

**C**hange **D**irectory

### ورود به یک پوشه

```bash
cd Documents
```

اگر پوشه در مسیر فعلی باشد.

### ورود با مسیر مطلق

```bash
cd /Users/macuser/Documents/Projects/farhadproject
```

### ورود به پوشه Home

```bash
cd
```
یا
```bash
cd ~
```

### بازگشت به پوشه والد

```bash
cd ..
```

### بازگشت دو مرحله بالا

```bash
cd ../..
```

### بازگشت به پوشه قبلی

```bash
cd -
```

### رفتن به مسیر با فاصله در نام

اگر پوشه‌ای نامش فاصله دارد، در دو کوتیشن بگذار:

```bash
cd "My Documents"
```
یا از `\` استفاده کن:
```bash
cd My\ Documents
```

## 🛠 تمرین: از Home به پروژه

بیا مسیری که در این پروژه استفاده کردیم را تمرین کنیم:

```bash
# شروع از Home
cd

# بررسی موقعیت
pwd
# /Users/macuser

# رفتن به Documents
cd Documents

# ساخت پوشه Projects (اگر نیست)
mkdir -p Projects

# رفتن به Projects
cd Projects

# رفتن به پروژه ما
cd farhadproject

# بررسی
pwd
# /Users/macuser/Documents/Projects/farhadproject

# لیست محتوا
ls -la
```

## 🎓 ترفند: بازگشت سریع

برای بازگشت به Home از هر جای فایل‌سیستم:
```bash
cd
```

برای رفتن به پروژه از هر جای فایل‌سیستم:
```bash
cd ~/Documents/Projects/farhadproject
```

## 🎓 ترفند: Tab Completion

سریع‌ترین راه برای نوشتن مسیر:

```bash
cd Doc<TAB>
```
خودش می‌شود `cd Documents/`.

```bash
cd ~/Doc<TAB>/Pro<TAB>/far<TAB>
```
خودش می‌شود `cd ~/Documents/Projects/farhadproject/`.

**صرفه‌جویی در تایپ + جلوگیری از اشتباه تایپی.**

## 🛑 خطاهای رایج

### `cd: no such file or directory`

پوشه وجود ندارد. با `ls` بررسی کن.

### `cd: permission denied`

اجازه ورود نداری (نادر). با `sudo` یا مجوز مناسب.

### `cd Documents\ Projects`

اگر نام پوشه فاصله دارد، باید یا کوتیشن بگذاری یا `\` قبل از فاصله.

## 🎁 خلاصه

| دستور | کار |
|---|---|
| `pwd` | مسیر فعلی |
| `ls` | لیست محتوای پوشه |
| `ls -la` | لیست کامل با فایل‌های مخفی |
| `cd X` | رفتن به پوشه X |
| `cd` | رفتن به Home |
| `cd ..` | یک مرحله بالا |
| `cd -` | بازگشت به پوشه قبلی |
