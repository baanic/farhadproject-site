# ترمینال چیست؟

## 🎓 مفهوم

**ترمینال** یک برنامه است که به تو اجازه می‌دهد با **خط فرمان** (Command Line) با کامپیوتر صحبت کنی.

به‌جای اینکه با ماوس روی آیکون‌ها کلیک کنی و منو باز کنی، **دستور** می‌نویسی و Enter می‌زنی.

### مقایسه ساده

| GUI (رابط گرافیکی) | ترمینال (خط فرمان) |
|---|---|
| روی آیکون پوشه دابل‌کلیک می‌کنی | `cd Documents` می‌نویسی |
| روی فایل راست‌کلیک → Delete | `rm file.txt` می‌نویسی |
| کپی → پیست | `cp source.txt dest.txt` می‌نویسی |

## 🎓 مفهوم: Shell چیست؟

وقتی ترمینال را باز می‌کنی، چیزی داخل آن اجرا می‌شود به نام **Shell**.

**Shell** یک برنامه است که:
1. دستور تو را می‌خواند.
2. آن را تفسیر می‌کند.
3. به سیستم‌عامل می‌فرستد.
4. نتیجه را به تو نشان می‌دهد.

### انواع Shell

| Shell | توضیح |
|---|---|
| **sh** | اولین Shell یونیکس (دهه ۷۰) |
| **bash** | GNU Bourne-Again Shell (دهه ۸۰) |
| **zsh** | Z Shell (دهه ۹۰) — **پیش‌فرض مک از سال ۲۰۱۹** |
| **fish** | Friendly Interactive Shell — مدرن |

### در مک، ما از Zsh استفاده می‌کنیم

وقتی ترمینال را در مک باز می‌کنی، به‌طور پیش‌فرض **Zsh** اجرا می‌شود.

**چطور بفهمم؟** این دستور را بزن:

```bash
echo $SHELL
```

خروجی: `/bin/zsh` یا مشابه.

## 🎓 مفهوم: Prompt چیست؟

وقتی ترمینال را باز می‌کنی، چیزی شبیه این می‌بینی:

```
macuser@macusers-MacBook-Pro ~ %
```

این را **Prompt** می‌گویند. یعنی: «ترمینال آماده است. دستورت را بنویس.»

### آناتومی Prompt

```
macuser@macusers-MacBook-Pro ~ %
   │            │           │ │
   │            │           │ └─ علامت آماده بودن
   │            │           └─── پوشه فعلی (~ یعنی Home)
   │            └─────────────── نام کامپیوتر
   └──────────────────────────── نام کاربری
```

- **`macuser`** = نام کاربری تو در مک.
- **`macusers-MacBook-Pro`** = نام کامپیوتر.
- **`~`** = پوشه Home تو (`/Users/macuser`).
- **`%`** = علامت آماده بودن.

## 🎓 مفهوم: دستور، فلگ، آرگومان

هر دستوری که می‌زنی، سه بخش دارد:

```
ls -la Documents
│   │    │
│   │    └── Argument (آرگومان) — روی چه چیزی اجرا شود
│   └─────── Flag (فلگ) — با چه تنظیماتی
└─────────── Command (دستور) — چه کاری
```

| بخش | توضیح | مثال |
|---|---|---|
| **Command** | کار اصلی | `ls` (لیست کردن) |
| **Flag** | تنظیمات | `-la` (نمایش کامل با جزئیات) |
| **Argument** | هدف | `Documents` (پوشه موردنظر) |

## 🛠 اجرا: اولین دستورها

ترمینال را باز کن و این‌ها را بزن:

### دستور ۱: تاریخ امروز

```bash
date
```

خروجی: تاریخ و ساعت فعلی. مثلاً:
```
Mon Sep 26 08:15:32 +0330 2026
```

### دستور ۲: چه کسی هستم؟

```bash
whoami
```

خروجی: `macuser` (نام کاربری مک تو).

### دستور ۳: کجا هستم؟

```bash
pwd
```

خروجی: مسیر کامل پوشه فعلی.

### دستور ۴: پیام چاپ کن

```bash
echo "سلام دنیا"
```

خروجی: `سلام دنیا`

## 💡 چرا این دستورها؟

این چهار دستور، **پایه همه چیز** هستند:
- `date`: اطلاعات سیستم.
- `whoami`: هویت کاربر.
- `pwd`: موقعیت فعلی.
- `echo`: چاپ متن (پایه اسکریپت‌نویسی).

در گام‌های بعدی، روی این‌ها ساخته می‌شود.

## 🎓 نکته: Autocomplete با Tab

یک ترفند فوق‌العاده: **Tab Completion**.

وقتی داری دستور یا مسیر می‌نویسی، فقط شروعش را بنویس و **Tab** بزن. Shell خودش کامل می‌کند.

**مثال:**
```bash
cd Doc<TAB>
```
Shell خودش تبدیل می‌کند به `cd Documents/`.

اگر چند گزینه وجود داشت، دو بار Tab بزن تا همه را ببینی.

## 🎓 نکته: تاریخچه دستورات

هر دستوری که می‌زنی، ذخیره می‌شود. با **کلید بالا/پایین** می‌توانی بین دستورهای قبلی پیمایش کنی.

**ترفند:**
- `↑` = دستور قبلی.
- `Ctrl + R` = جستجو در تاریخچه. تایپ کن تا پیدا کنی.

## 🛑 اگر خطا دیدی

### خطای رایج

```
zsh: command not found: ls
```

یعنی دستور `ls` پیدا نشد. این ممکن است به دلایل زیر باشد:
- تایپ اشتباه (مثلاً `sl` به‌جای `ls`).
- دستور نصب نیست.

### خطای دیگر

```
zsh: no such file or directory: file.txt
```

یعنی فایلی که می‌خواهی بخوانی وجود ندارد. مسیر را بررسی کن.
