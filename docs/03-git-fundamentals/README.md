# 🌳 مبانی Git

## این بخش چیست؟

در این بخش، **Git** را یاد می‌گیری — ابزاری که تاریخچه تغییرات پروژه را نگه می‌دارد.

## چرا Git یاد بگیریم؟

### ۱. تاریخچه تغییرات
هر تغییری که در پروژه می‌دهی، ثبت می‌شود. می‌توانی به هر نسخه قبلی برگردی.

### ۲. همکاری با تیم
چند نفر می‌توانند روی یک پروژه کار کنند بدون اینکه کار هم را خراب کنند.

### ۳. بکاپ آنلاین
با GitHub، کدت روی اینترنت ذخیره می‌شود. اگر لپ‌تاپ خراب شد، کدت امن است.

### ۴. استاندارد صنعت
هر شرکت و تیمی از Git استفاده می‌کند. **بدون Git، نمی‌توانی برنامه‌نویس حرفه‌ای شوی.**

### ۵. نمایش به کارفرما
کارفرمای آینده می‌تواند تاریخچه کار تو را ببیند.

## فلسفه این مستندات

Git برای بسیاری، «ترسناک» است. اما این ترس، ناشی از **نفهمیدن مدل ذهنی** Git است.

در این مستندات:
- از مفاهیم شروع می‌کنیم، نه دستورات.
- هر دستور، با مثال از **پروژه واقعی ما** توضیح داده شده.
- هر مفهوم، با **قیاس روزمره** توضیح داده می‌شود.

بعد از این بخش، Git دیگر «جعبه سیاه» نیست. یک ابزار است که می‌فهمی چطور کار می‌کند.

## پیش‌نیاز

| ابزار | بررسی |
|---|---|
| Terminal | `pwd` کار کند |
| Git نصب | `git --version` کار کند |
| حساب GitHub | [github.com](https://github.com) |

**بررسی نصب Git:**

```bash
git --version
```

اگر نسخه‌ای مثل `git version 2.50.1` دیدی، آماده‌ای.
